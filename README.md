# V-Influencer Studio Landing Page

This is a static landing page prototype. Make sure you start a local server **from the repo root** (the folder that contains `index.html`).

## Run locally

```bash
cd /workspace/gokendepo
python -m http.server 8000
```

Then open:

```
http://127.0.0.1:8000/
```

> Tip: `http://127.0.0.1:8000/index.html` also works as long as the server is started from this directory.
